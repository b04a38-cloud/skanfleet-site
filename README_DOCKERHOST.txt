СКАНФЛИТ v19 — Dockerhost

Сайт не требует API-ключа карты.
Карта: MapLibre GL JS + OpenFreeMap.

Состав:
- index.html
- assets/logo.jpg
- assets/marker.svg
- assets/marker-active.svg

Для Dockerhost загрузите содержимое этой папки в репозиторий GitHub и собирайте контейнер как статический сайт.

Важно: для загрузки картографического стиля нужен доступ браузера к интернету. Сам сайт и кнопка «Подробнее» не зависят от загрузки карты.
